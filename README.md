# DataCenterAccessSystem · 数据中心机房准入系统

面向数据中心、机房等受控区域的**访客准入管理系统**，覆盖从「来访工单 → 多级审批 → 访客登记 → 安全学习 → 在线考试 → 准入凭证」的完整闭环。

采用**前后端分离**架构，三端协同：

| 端 | 技术栈 | 用户 |
|---|---|---|
| 微信小程序 | 原生 JavaScript / WXML / WXSS | 访客、业务部成员 |
| Web 管理台 | Vue3 + Element Plus（yudao-ui 裁剪） | 管理员 |
| 后端 | Python 3 + FastAPI + PyMySQL | 统一服务端 |

```text

       └───────────┬───────────┘

           │     MySQL    │
           │ dc_access_system │
           └──────────────┘
```

## 用户角色与功能

### 1. 访客（小程序）
- 注册 / 登录（姓名、**身份证号**、手机号、密码、公司）
- 首页展示准入状态（六态：未预约 / 预约审批中 / 预约成功 / 工单审批中 / 审批通过 / 审批未通过）
- 阅读安全须知、参加限时考试（总分 100，合格 70）
- 查看准入凭证、历史凭证、我的考试、我的账号
- 快速预约（无需预置工单，由部门主管直属审批）

### 2. 业务部成员（小程序）
- 注册 / 登录
- 提交工单：来访单位、来访人员（多人，姓名/身份证/电话/单位）、进出时间、进出原因、活动区域、联系人、陪同人员，以及管理员配置的**自定义字段**
- 草稿箱（保存 / 编辑 / 提交 / 删除）
- 查看工单详情与审批进度

### 3. 管理员（Web 管理台）
- 登录 / 待办任务 / 已办任务（审批通过、驳回 + 意见）
- 工单列表、预约列表、业务部成员管理
- **题库管理**（新增 / 修改 / 删除 / 查看）
- **自定义工单内容**（增删改工单字段结构，支持文本/选择框/日期/时间等输入方式，可恢复默认）
- **审批流程配置**（拖拽连线自定义审批流，按访问原因分配，支持多层）

## 核心业务流程

```text
业务部提交工单
    ↓
按「访问原因」匹配审批流（如：设备维护 → 审批流1）
    ↓
审批流内各节点管理员依次审批（任一驳回则结束）
    ↓
工单审批通过
    ↓
访客注册/登录（按身份证号匹配已通过工单）
    ↓
安全学习 → 在线考试 → 自动判分
    ↓
考试通过 → 生成准入凭证
    ↓
凭凭证进入机房
```

> 无预置工单的访客可走「快速预约」，由部门主管单级审批，通过后同样可考试获取凭证。

## 关键技术特性

- **按访问原因分配审批流**：每个「访问原因」（设备维护、施工、参观考察…）对应一条独立审批流，可配置不同审批人选；新增访问事务自动生成对应审批流。
- **拖拽连线配置审批流**：管理台可视化画布，拖动节点、拖线建立审批顺序，支持任意层级，单链审批。
- **动态工单字段**：工单结构后台可配置（增删字段、设置输入方式），小程序表单、工单详情、审批详情、凭证页均按字段定义动态渲染。
- **身份证匹配**：访客按身份证号在工单来访人员中匹配，而非公司名。
- **零依赖 JWT 鉴权**：标准库 HMAC-SHA256 实现，区分 admin / business 两种用户类型。

## 快速启动

### 1. 数据库
导入 `database/` 下的 schema 脚本（v0.3 → v0.6），创建库 `dc_access_system`。

### 2. 后端

```bash
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

接口文档：http://127.0.0.1:8000/docs

### 3. 管理台

```bash
cd admin-web
npm install --legacy-peer-deps   # 首次
npm run dev
```

接口地址在 `.env.local` 的 `VITE_BASE_URL`（默认 http://127.0.0.1:8000）。

### 4. 小程序

用微信开发者工具导入 `miniprogram/` 目录（AppID 已配置）。

- 模拟器测试：`miniprogram/config.js` 的 `BASE_URL` 填 `http://127.0.0.1:8000`
- 手机真机测试：`BASE_URL` 改成电脑局域网 IP，后端需 `--host 0.0.0.0`，开发者工具勾选「不校验合法域名」或使用「真机调试」
